# Northstar

**This project has been discontinued and its source removed.**

Northstar was a personal Android project: a companion app for a Royal
Enfield Himalayan 450 that connected to the bike's Tripper dash, built
to explore low-power turn-by-turn navigation on the dash's round display
while keeping the phone screen off.

At Royal Enfield's request, development has stopped and the source code
has been taken down from this repository.

Thanks to everyone who tried it, tested builds, or opened issues along
the way.
